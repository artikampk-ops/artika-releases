# ARTIKA Browser releases

## Install

### Zorin, Ubuntu, Linux Mint or Debian

1. Download **[artika-browser-amd64.deb](https://github.com/artikampk-ops/artika-releases/releases/latest/download/artika-browser-amd64.deb)**.
2. Double-click the downloaded file and press **Install**.

### Windows

Download **[artika-browser-setup.exe](https://github.com/artikampk-ops/artika-releases/releases/latest/download/artika-browser-setup.exe)** and run it.

The links above always point to the newest version. ARTIKA updates itself after
installation, from either installer. Every version is listed under
[Releases](https://github.com/artikampk-ops/artika-releases/releases), together
with the AppImage and portable Windows builds.

## About this repository

This repository is a public download mirror for ARTIKA Browser builds.
Clients download updates from here and verify the sha256 of every file against
the update manifest on the control plane.

Releases are published by the control-plane maintainer; source code lives in the
private `artikampk-ops/artika-control-plane` repository.
